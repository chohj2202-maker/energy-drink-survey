# 인터넷에 공개하는 방법

이 프로젝트는 Render에서 바로 배포할 수 있도록 준비되어 있습니다.

## 가장 쉬운 방법

1. GitHub에 이 폴더의 파일을 새 저장소(repository)로 올립니다.
2. Render에서 GitHub 저장소를 연결합니다.
3. `render.yaml`을 사용하는 Blueprint 방식으로 배포합니다.
4. 배포가 끝나면 `https://...onrender.com` 형태의 주소가 생깁니다.
5. 그 주소가 설문 링크입니다.
6. `https://...onrender.com/qr`에 접속하면 설문용 QR 코드가 나옵니다.

## 관리자

`https://...onrender.com/admin`

관리자 비밀번호는 Render 환경변수 `ADMIN_PASSWORD`에 직접 정합니다.

## 주의

Render의 무료 Postgres는 현재 30일 후 만료되는 제한이 있습니다.
따라서 짧게 진행하는 수행평가에는 사용할 수 있지만, 30일보다 오래 데이터를 보관하려면 유료 데이터베이스나 다른 영구 저장소가 필요합니다.

무료 Web Service는 일정 시간 사용되지 않으면 잠들 수 있어서 첫 접속이 느릴 수 있습니다.

## QR

배포가 끝난 뒤 생성된 실제 주소를 QR이 사용합니다.
관리자 페이지의 `QR 코드 보기`에서도 확인할 수 있습니다.
