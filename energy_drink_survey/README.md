# 시험 기간 에너지 음료 설문조사 웹사이트

학교 수행평가용으로 만든 설문조사 웹사이트입니다.

## 기능

- 휴대폰에서도 답할 수 있는 설문 페이지
- Q1~Q3 응답 저장
- SQLite 데이터베이스에 자동 저장
- 관리자 비밀번호로 결과 페이지 보호
- 총 응답자 수 표시
- 문항별 응답 수와 백분율 표시
- 막대그래프로 결과 표시
- QR 코드 자동 생성

## 실행 방법 (Windows)

1. Python이 설치되어 있는지 확인합니다.
2. 이 폴더에서 터미널을 엽니다.
3. 아래 명령을 실행합니다.

```text
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

4. 인터넷 브라우저에서 아래 주소로 들어갑니다.

```text
http://127.0.0.1:5000
```

## 관리자 페이지

주소:

```text
http://127.0.0.1:5000/admin
```

기본 관리자 비밀번호:

```text
1234
```

실제 공개 사이트로 사용할 경우 비밀번호를 바꾸는 것을 권장합니다.

## QR 코드

관리자 페이지의 'QR 코드 보기'를 누르면 현재 설문 주소의 QR 코드가 만들어집니다.

중요:
127.0.0.1은 내 컴퓨터에서만 접속되는 주소입니다.
학교 친구들이 각자 휴대폰으로 접속하려면 이 사이트를 인터넷에 배포해서 공개 URL을 만들어야 합니다.

공개 URL이 생긴 뒤에는 환경변수 PUBLIC_URL에 그 주소를 넣으면 QR 코드가 그 주소를 가리키도록 만들 수 있습니다.
